# @nexus/cards

Catalog adapters for game-core. Runtime titles live in `packages/game-core/src/catalog/` so core stays dependency-free.

**20 Majors (this drop):** ranks 0–9 × Sun/Moon. Rank 0 The Sun / The Moon stay in hold. #1 The Wise / The Daydreamer and #3 The Lucid Dreamer / The Sheman are Eclipse evolution options. Ranks 2 and 4–9 shuffle into the L1 deck. Impacts are not encoded.

Art production sheets (Crystals & Earth, etc.) stay in `C:\P6` until we import the other seven lineages the same way. Do not load `NEXUS_92_MASTER` at runtime.
